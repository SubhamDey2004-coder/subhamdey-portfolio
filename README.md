# Subham Dey — AI/ML Engineering Portfolio

Personal portfolio website for showcasing my projects, skills, experience, and contact links.

## Live website
After enabling GitHub Pages, the site will be available at:
https://subhamdey2004-coder.github.io/subhamdey-portfolio/

## Run locally
Open `index.html` in any modern browser. This site uses HTML, CSS, and vanilla JavaScript; no build step is required.

## Deploy with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site.
